# AxmatCord

![AxmatCord](media/discord.png)

Неофициальный нативный клиент для Discord. Быстрая установка без прав администратора, встроенные автообновления.

## Скачать
👉 **[Скачать AxmatCord для Windows](https://github.com/xHarmless2/AxmatCord/releases/latest)** — файл `axmatcord-*-Setup.exe`

## Плагины и темы
Свои плагины и темы делать несложно — гайд: **[EXTENSIONS.md](EXTENSIONS.md)**.

## Обновления
Клиент обновляется автоматически: **Настройки → Обновления**.
